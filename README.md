_This is a collection of small projects and experiments. Mostly just me playing with Claude Code._

## Projects

### [led-control](./led-control)
Single-file Linux SBC LED control utility (sysfs triggers) with optional systemd persistence across reboots.

### [nadsat-dictionary](./nadsat-dictionary)
Command-line dictionary tool for Nadsat, the fictional slang from "A Clockwork Orange".

### [npa-nicar-analysis](./npa-nicar-analysis)
Jupyter notebook analysis of NICAR-L LISTSERV archives, including monthly post counts from 2002 to 2023.

### [pi-health-check](./pi-health-check)
Raspberry Pi system health checker with model-aware diagnostics (temperature, power, storage, firmware, and more).

### [python-datawrapper](./python-datawrapper)
Example scripts using the Datawrapper Python API to build and publish an annual totals chart from CSV data.

### [wikipedia-date-app](./wikipedia-date-app)
Find Wikipedia articles containing specific dates. Includes both Python CLI and Svelte web app.

## Development

These projects were developed with AI assistance, including Claude Code.
